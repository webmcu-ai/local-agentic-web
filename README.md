



# local-agentic-web
A local private agentic agent using your web browser



Live webpage here https://webmcu-ai.github.io/local-agentic-web/index.html



Instructions on the webpage.

Basically uses webGPU or Ollama to load LLM's then gives you Javascript control of everything. Allows multiple input formats, has a text to image and an image to image generator, has an agentic and coding agent and various ways to view the output as HTML, Latex or SVG.
